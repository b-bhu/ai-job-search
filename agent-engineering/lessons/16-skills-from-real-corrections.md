# Lesson 16 — Skills from real corrections

Prepared lesson. Status: Not started. Track: Core.

## Objective

Turn a recurring correction into a reusable procedure.

## Predict

You corrected the same verification omission three times. What should a useful skill record?

Ask this first in conversation and wait. The following explanation is prepared material, not learner evidence.

## Analogy

After burning several batches, the chef writes a tested oven procedure. A cookbook full of untried advice is less dependable.

## Model

Mine skills from real interventions and recall. Record the trigger, required evidence, steps and stopping conditions. Keep the strongest enforceable rules in types or checks. pstack supplies reusable workflows. Dune is the speaker's private framework, so it is not a public dependency to install.

1. **Real correction**: Observed miss
2. **Reusable procedure**: Trigger + steps
3. **Use on new case**: Check transfer
4. **Revise from evidence**: Keep learning
