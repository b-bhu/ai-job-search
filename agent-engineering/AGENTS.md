# Agent-engineering course

This directory is a personal learning course. Read README.md and tutor.md, then progress.md, the latest session-log.md entry and open review-queue.md entries before teaching. Ask one question at a time and wait. Record actual learner evidence and the exact next question. A browser read mark does not prove mastery.

Keep this course separate from ../learning/. Preserve existing Solana course progress and unrelated work. Course examples use fake/local fixtures. No production code changes, installs, signing or submission are authorized by a lesson.
