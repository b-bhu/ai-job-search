# Agent engineering, one idea at a time

A self-paced visual course for Bibhu, based on Lauren Tan's agent engineering talk and interview, Runar Bjarnason's constraints talk, and our TypeScript/Solana adaptations.

## Start or resume

Open [the visual course](index.html) in your browser. Begin with Lesson 01. Each lesson has four small screens: Predict, Model, Example and Your turn. Move whenever you are ready. There are no deadlines or time estimates.

For interactive teaching in the new project session, say **“Continue my agent-engineering course.”** A new chat in this project can read this file and [tutor.md](tutor.md). The exact pending question is in [progress.md](progress.md).

You can say “Explain another way”, “Give me a hint”, “Review my answer”, or “Show my progress”. The tutor asks one question, waits for your answer, and adapts. Use ordinary language. Code snippets are illustrations, not a syntax exam.

## Your course desk

- [Visual lessons](index.html): one screen at a time, diagrams, optional code, hints and a browser bookmark.
- [Roadmap](roadmap.md): all 18 lessons. Lessons 12–13 are an optional deeper track that you can revisit later.
- [Progress](progress.md): durable tutor record and exact next task.
- [Session log](session-log.md): actual attempts, help and feedback.
- [Review queue](review-queue.md): concepts that evidence says need another explanation.
- [Sources](sources.md): timestamps, attribution, caveats and coverage map.
- [Tutoring procedure](tutor.md): pacing and record-keeping agreement.
- [Lesson notes](lessons/): readable versions of every prepared lesson.

The visual course saves its place and your notes in this browser when storage is available. It shows whether saving works. Browser notes do not update the tutor files. Use “Show resume text” and paste that text into the course chat for review and a durable record. Clearing browser data can remove browser notes. A “read” mark records studying, never assessed mastery.

Everything is local. No packages, integrations, wallets, mainnet transactions or product code changes are part of this course. The existing backend-to-Solana course and its records remain separate.
